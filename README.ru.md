# phoneoperator

[![npm](https://img.shields.io/npm/v/phoneoperator?color=0e7c66)](https://www.npmjs.com/package/phoneoperator)
[![JSR](https://jsr.io/badges/@mrprolopstar/phoneoperator)](https://jsr.io/@mrprolopstar/phoneoperator)

[English version](README.md) · [Песочница](https://mrprolopstar.github.io/phoneoperator/)

Оператор и регион российского номера телефона офлайн. Данные взяты из официального реестра нумерации Минцифры, лежат внутри пакета и обновляются каждую неделю. Без зависимостей и сетевых запросов, работает в Node, Deno, Bun и браузере.

```sh
npm install phoneoperator
```

```ts
import { lookup } from 'phoneoperator';

lookup('+7 916 123-45-67');
// {
//   number: '+79161234567',
//   national: '9161234567',
//   code: '916',
//   type: 'mobile',
//   operator: { name: 'ПАО "Мобильные ТелеСистемы"', inn: '7740000076', brand: { id: 'mts', name: 'МТС' } },
//   region: 'Город Москва, Московская область',
//   locality: null
// }

lookup('8 (999) 123-45-67')?.operator.brand?.name; // 'Yota'
lookup('+1 212 555 0100');                         // null
```

## Мобильные и стационарные

Основной импорт покрывает мобильные номера (9xx), это около 45 КБ в gzip. Стационарные (3xx, 4xx, 8xx) добавляют 433 тысячи диапазонов и около 640 КБ, поэтому они вынесены в отдельный импорт с тем же API:

```ts
import { lookup } from 'phoneoperator/full';

lookup('+7 495 123-45-67'); // { type: 'landline', operator: { name: 'ПАО "Ростелеком"', ... }, region: 'Город Москва', ... }
lookup('8 800 555 35 35');  // { type: 'landline', region: 'Российская Федерация', ... }
```

Для стационарных номеров в `locality` лежит населённый пункт, если реестр его указывает.

## API

| Функция | Результат |
|---|---|
| `lookup(input)` | `PhoneInfo` или `null` для неверного ввода и невыделенных диапазонов |
| `parsePhone(input)` | 10 цифр номера или `null`; понимает `+7`, `7`, `8` и обычные разделители |
| `formatPhone(input)` | `'+7 912 345-67-89'` или `null` |
| `BRANDS` | Бренд по ИНН оператора: МТС, МегаФон, Билайн, T2, Yota, Т-Мобайл, СберМобайл и другие |
| `updated` | Дата снимка реестра в пакете |

`operator.brand` равен `null` у операторов без потребительского бренда, а `operator.name` и `operator.inn` всегда содержат юрлицо из реестра.

## Перенесённые номера

Реестр говорит, какому оператору выделен диапазон. С 2013 года номер можно перенести к другому оператору, а база перенесённых номеров закрыта, поэтому для такого номера `lookup` вернёт исходного оператора. Регион при переносе не меняется.

## Данные

Раз в неделю реестр скачивается и проверяется: заголовок, ёмкость каждого диапазона, отсутствие пересечений, наличие большой четвёрки операторов. Затем он сжимается и сравнивается с версией в пакете. Если что-то изменилось, запускаются тесты, в том числе проверка трёх номеров из каждой из 450 тысяч строк реестра, и новая минорная версия сама публикуется в npm.
